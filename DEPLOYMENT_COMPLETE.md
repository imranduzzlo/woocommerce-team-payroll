## Configuration

### Setting Achievement Period
1. Go to **WooCommerce → Team Payroll → Performance Settings**
2. Find **Achievement Period** dropdown
3. Select desired period type:
   - Daily
   - Weekly
   - Monthly
   - Quarterly
   - Half-Yearly
   - Yearly
4. Click **Save Settings**

### Weekly Period Configuration
- Go to **Settings → General**
- Find "Week Starts On" setting
- Select desired day (Sunday, Monday, etc.)
- Weekly periods will reset on that day

## Known Limitations

1. **SessionStorage Notifications**
   - Notifications show again if page is refreshed
   - This is intentional for user experience
   - Can be changed to localStorage if needed

2. **History Limit**
   - Only last 365 periods kept
   - Oldest records automatically removed
   - Configurable if needed

3. **Period ID Formats**
   - Different formats for different period types
   - Documented in getPeriodLabel function
   - Consistent across all views
